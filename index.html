What to check before ordering

Confirm the exact variant

Open the CAFANS product page and follow the source listing. Check stock for your color and size. Compare garment measurements with an item you already own.

Verify agent support

Check that your shopping agent accepts the exact listing. Review warehouse photo options, return deadlines and who pays return postage before placing the order.

Compare the delivered total

Add the item price, domestic delivery, agent fees and international shipping. Compare quotes for the same parcel dimensions and check if taxes or duties are included.

ACBuy spreadsheet FAQ

What is an ACBuy spreadsheet?

It is a list of products and links shoppers can use to compare items before placing an order through an agent. This guide uses CAFANS listings, and both main buttons open CAFANS.

Can I order every listing through ACBuy?

Eligibility depends on the seller link, the item and the agent’s current rules. Open the original listing and verify that the agent accepts it before paying.

What should I check in warehouse QC photos?

Check that the size label, color, quantity and visible condition match your order. If the measurements matter, ask for a photo showing the ruler placement while the return window is open.

Can I save the catalog to Google Sheets or Excel?

Filter the catalog and choose “Download results CSV.” The file contains the visible listings in their current order, with the product name, category, reference price and CAFANS URL.
